Why some bodies are hard to place

Public money and a public job do not always point the same way. A body can do a public job on private money, or take public money for a private job. That is where the judgement calls sit.

What kind of code is it?

Codes of conduct are not all the same. Some are just a statement of values; others name the seven principles, set binding rules, and say what happens if you break them. This is the scale we place each code on.
